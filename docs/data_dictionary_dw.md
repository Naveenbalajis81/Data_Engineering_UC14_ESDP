# Data Dictionary: `dw` schema (UC14 ESDP)

Generated from the Sprint 2 database backup. 11 dimension tables and 6 fact tables. Row counts are from the master load run on 2026-10-16.

## Notes

- Every table has a surrogate primary key named `<table>_key`. Dimension business keys carry a UNIQUE constraint.
- **The database has no foreign key constraints.** Fact-to-dimension links below are logical. `audit.run_dw_checks()` is what verifies there are no orphan keys.
- `fact_inventory_movement.material_id` is a plain text ID, not a key to `dim_material`.
- Lineage for every table is in `metadata.source_to_target`.
